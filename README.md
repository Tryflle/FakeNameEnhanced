# FakeNameEnhanced
1.8.9 forge rewritten and better version of fakename that works with patcher optimized font renderer <br >
[Available on Modrinth!](https://modrinth.com/mod/fakenameenhanced)
# Usage
`/fakename <name>` - set name <br >
`/fakename` - reset name <br >
`/fakenamecolor` - shows all enumchatformatting options you can use
